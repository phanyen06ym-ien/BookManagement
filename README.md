# Book Management

## Giới thiệu

Book Management là ứng dụng Web quản lý sách được xây dựng bằng ASP.NET Core MVC.

Ứng dụng sử dụng Entity Framework Core để làm việc với cơ sở dữ liệu SQL Server theo phương pháp Code First.

## Chức năng

- Hiển thị danh sách sách
- Thêm sách mới
- Xem chi tiết sách
- Chỉnh sửa thông tin sách
- Xóa sách
- Kiểm tra dữ liệu nhập vào

## Thông tin sách

Mỗi sách gồm:

- Mã sách
- Tên sách
- Tác giả
- Giá
- Số lượng
- Năm xuất bản

## Công nghệ sử dụng

- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- SQL Server / LocalDB
- Bootstrap

## Cơ sở dữ liệu

Project sử dụng Entity Framework Core Code First.

Sau khi tải project, có thể tạo/cập nhật database bằng lệnh:

```powershell
Update-Database
```

Database sử dụng:

`BookManagementDB`
